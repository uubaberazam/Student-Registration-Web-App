Supabase Quick Setup Guide

Connect this app to your Supabase project in 3 simple steps:

  1. Create or open your Supabase project:
    Visit supabase.com and create a new project.
  2. Run Database Schema:
    In Supabase Dashboard, open SQL Editor, paste the content of supabase/schema.sql and click Run.
  3. Configure config.js:
    Go to Project Settings → API, copy your Project URL and anon public API key into config.js.
